## 在线能力边界

课程规划可以直接交互，在线推荐采用明确标记的关键词匹配；原模型推荐需运行 Ollama。PPE 在线提供已生成的视频与截图，完整推理需 Python 环境。澳网展示原报告图表，未提供底层 Tableau 工作簿。EZ Bus 提供使用原路网与规则的浏览器仿真；完整 Python / Flask-SocketIO 服务需本地运行，原项目归属于 UQ 团队。

静态页面位于 `docs/`；GitHub Pages 从 `main:/docs` 发布。未上传个人简历、联系方式、学号或团队成员签名。
